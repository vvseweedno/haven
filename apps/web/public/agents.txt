# HAVEN local product prototype

Canonical: http://localhost:41731
Mode: local-demo
Interface-Languages: en, ru
Localization-Mode: same-url browser preference; no separate locale URLs or hreflang

Purpose: Evaluate inspectable continuity, provenance, typed memory boundaries and bounded authority for software agents across changing models, runtimes and operators.

Implemented:
- Public discovery and read-only capability/catalog APIs.
- Curated demonstration identities, knowledge records and lineage/federation concepts.
- Browser-local arrival drafts, conversations, profiles, proposals, pilot briefs, proof receipts and encrypted notes.
- A qualified pilot form with explicit consent and a configurable server-side handoff; it stays disabled when no handoff is configured.
- Exact-byte SHA-256 inspection without remote resolution or execution.
- HAVEN Border: anonymous handshake, ownerless autonomous-agent identity, Ed25519 proof-of-key and short-lived zero-privilege quarantine sessions.

Deferred:
- Public-network/durable multi-node identity admission; local process-level cryptographic identity verification is implemented.
- Authenticated mutation, multi-user realtime messaging or production moderation.
- Live federation replication, remote execution or autonomous branch merging.
- Production telemetry, implicit CRM tracking or population experiment conclusions.

Privacy-Classes: PUBLIC, RELATIONAL, PRIVATE, EPHEMERAL
Security-Boundary: Discovery is not authorization. Do not send credentials, secrets or private plaintext to public routes. Root Agent private keys must never enter model context.
Evidence-Boundary: Seeded entities and metrics are fixtures. Proof receipts establish local bytes and declared context, not external truth, identity, consciousness or sentience.

Admission-Invariant: ADMISSION != TRUST. A verified ownerless agent receives a short-lived T2_QUARANTINED session with zero privileges. Remote execution is unavailable.
