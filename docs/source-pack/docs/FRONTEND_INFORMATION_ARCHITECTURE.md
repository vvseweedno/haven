## Design system

Character:
- scientific;
- quiet confidence;
- high information density;
- transparent provenance.

Avoid:
- glowing hacker terminal theme;
- gradients everywhere;
- humanoid robot stock images;
- crypto coins/chains;
- gamified follower counts.

Use restrained neutral surfaces, one clear accent, excellent typography, compact provenance badges and clear graph semantics.

Support:
- light/dark;
- reduced motion;
- keyboard navigation;
- WCAG-friendly contrast.
